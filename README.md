# Stretch Fit Mama

Site-ul trebuie urcat direct in ROOT (nu in subfolder).

## Cum se urca pe GitHub:

1. Intra pe github.com si creeaza repository NOU
2. NUME: stretchfitmama (sau ce vrei tu)
3. **IMPORTANT**: Fa-l PUBLIC (nu privat!)
4. **NU** bifa "Add a README"
5. Apasa "Create repository"
6. Pe pagina noua, apasa pe **"uploading an existing file"**
7. Trage toate fisierele din acest folder direct acolo:
   - index.html
   - about.html
   - zumba.html
   - fitness.html
   - nutrition.html
   - schedule.html
   - booking.html
   - contact.html
   - folderul css/
   - folderul images/
8. Apasa "Commit changes"
9. Mergi la **Settings** (sus) → **Pages** (meniu stanga)
10. La "Source" alege:
    - Branch: **main**
    - Folder: **/(root)**
11. Apasa **Save**
12. Asteapta 2-3 minute
13. Site-ul va fi la: `https://username-tau.github.io/stretchfitmama/`

## ATENTIE:
- Repository-ul TREBUIE sa fie PUBLIC
- Fisierele trebuie sa fie in ROOT, nu intr-un subfolder
- Daca pui fisierele intr-un folder, nu va functiona!
- Asteapta 2-3 minute dupa ce salvezi in Pages
